# Decisions

Architecture decision records (ADRs) for `eshu-collector-confluence`. An ADR is a short
note that says what we decided, why, and what it costs us, written
when the decision is made so nobody has to dig it out of a pull
request later.

## Index

| ADR | Title | Status |
| --- | --- | --- |
| (none yet) | No decisions are recorded here yet | — |

When the first real decision lands, add it as `0001-<slug>.md` in
this folder and add a row above. Please don't backfill rationale for
choices that were never recorded; if it isn't written down somewhere
verifiable, it doesn't get an ADR retroactively.

## Template

```markdown
# ADR-0001: <short title>

Status: proposed | accepted | superseded by ADR-XXXX
Date: YYYY-MM-DD

## Context

What forced a decision, in plain terms.

## Decision

What we chose.

## Consequences

What gets easier, what gets harder, and what to watch.
```
